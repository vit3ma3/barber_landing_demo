# Барбершоп Север — лендинг (демо)

Одностраничный сайт для вымышленного барбершопа. Демо-проект для портфолио.
Работает в паре с Telegram-ботом записи [@barber_sever_demo_bot](https://t.me/barber_sever_demo_bot):
услуги, цены, мастера и часы работы совпадают с `config.py` бота.

**Живая версия:** https://vit3ma3.github.io/barber_landing_demo/

## Что внутри

- Чистые HTML, CSS и немного vanilla JS — без сборщиков и зависимостей.
- Mobile-first вёрстка, проверена на ширине 375 px и на десктопе.
- Секции: первый экран, услуги и цены, мастера, отзывы, частые вопросы (аккордеон), контакты.
- Мета-теги для превью ссылки (Open Graph, Twitter Card), favicon и иконка для iOS.
- Шрифты Unbounded и Inter из Google Fonts (лицензия SIL OFL). Чужих фото и логотипов нет:
  графика и заглушки мастеров нарисованы на CSS/SVG.

```
index.html               страница
css/style.css            стили
js/main.js               меню, аккордеон FAQ
assets/favicon.svg       иконка вкладки
assets/apple-touch-icon.png
assets/og-image.png      картинка превью ссылки 1200×630
.nojekyll                отключает обработку Jekyll на GitHub Pages
```

## Локальный просмотр

Откройте `index.html` в браузере — больше ничего не нужно.

## Как включить GitHub Pages

1. Запушьте репозиторий на GitHub (ветка `main`).
2. Откройте репозиторий → **Settings** → **Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
4. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу
   `https://<логин>.github.io/<имя-репозитория>/` — ссылка будет вверху страницы Settings → Pages.

Если репозиторий переименован или опубликован под другим аккаунтом, поправьте абсолютные
ссылки в `index.html` — `og:url` и `og:image`. Превью ссылки в мессенджерах берёт картинку
только по полному адресу.

## Как адаптировать под реального клиента

- Ссылка на бота: замените `barber_sever_demo_bot` в `index.html` (3 места).
- Цвета и шрифты: переменные в начале `css/style.css`.
- Фото мастеров: замените блоки `.master__photo` на `<img>`.
- Картинка превью: `assets/og-image.png`, 1200×630.
